## How do I evaluate values across several years without adjusting everything every year?

<!-- abschnitt: prio=B; gewicht=16; readme=partial; cluster=outputs-viz-04,setup-ui-30; features=year-statistics-archive,current-year-months,output-tree-layout,current-year-previous,output-basic-period-states -->
<!-- muss beantworten: currentYear-States statt Jahresordner; Langzeitauswertung. -->

Use the states under `sourceanalytix.0.<device>.currentYear`. Their IDs never change, not even at the turn of the year. To compare across years, record the previous periods with a history adapter or read the archive under `sourceanalytix.0.<device>.<year>`.
<!-- quelle: code=main.js; forum=411837; forum=527370 -->

| Folder | Content |
|---|---|
| `currentYear.<category>.01_currentDay` to `05_currentYear` | running periods |
| `currentYear.<category>.01_previousDay` to `05_previousYear` | closed previous periods |
| `currentYear.<category>.weeks`, `months`, `quarters` | every week, month and quarter of this year |
| `<year>.<category>.weeks`, `months`, `quarters` | archive of a calendar year, a new folder each year |
<!-- quelle: code=main.js -->

`<category>` is `consumed` or `delivered`, `costs` or `earnings`, and `meterReadings`.
<!-- quelle: code=main.js -->

You decide which folders are created in the instance settings under "Main settings": "Current year" for `currentYear`, "Year statistics" for the archive. If you turn an option off, the page asks first, because SourceAnalytix then deletes those states of the current year. Earlier years stay.
<!-- quelle: code=admin/jsonConfig.json; code=admin/i18n/en.json; code=io-package.json; issue=#1311 -->

For long-term charts, record for example `03_previousMonth` and `05_previousYear`. Each value arrives once per period, timestamped 23:59:59 on the last day of the period. A year's weeks are in the folder of the year the calendar week belongs to.
<!-- quelle: code=main.js; code=lib/calculation.js; forum=1359624; issue=#1256 -->

**See also:** [Datapoints for Grafana/InfluxDB](#datapoints-use-grafana-influxdb) · [Instance settings](../03.referenz/01.einstellungen.md#instance-settings-exist-periods-decimals) · [Turn of the year](../03.referenz/02.states-und-meldungen.md#happens-turn-year)

## Which datapoints do I use for Grafana/InfluxDB?

<!-- abschnitt: prio=B; gewicht=13; readme=missing; cluster=outputs-viz-23,outputs-viz-24; features=current-year-months,output-basic-period-states,output-cumulative-reading,current-year-weekday,current-year-weeks -->
<!-- muss beantworten: Geeignete States, Wochen-/Monatsvergleich, Tagesbalken. -->

For bar charts, the previous periods under `currentYear.<category>`: `01_previousDay`, `02_previousWeek` and `03_previousMonth`. They get exactly one value per period, even when it is 0. For your own evaluations, `cumulativeReading` is enough.
<!-- quelle: code=main.js; forum=816700; forum=982104; forum=554544 -->

| Chart | State |
|---|---|
| Daily bars | `01_previousDay` |
| Compare weeks | `02_previousWeek` |
| Compare months | `03_previousMonth` |
| Today's curve | `01_currentDay` |
| Calculate everything yourself | `cumulativeReading` |
<!-- quelle: code=main.js; code=lib/calculation.js -->

1. On the "Objects" tab, turn on recording with your history adapter for these states, as a number.
2. Plot them in Grafana as bars without further summing. Each point already is the consumption of the whole period.
<!-- quelle: code=main.js; forum=795671; forum=847925; forum=503841 -->

The first value arrives after the first period rollover, so for `01_previousDay` after midnight.
<!-- quelle: code=main.js -->

**See also:** [Yesterday, last week, last month](../03.referenz/02.states-und-meldungen.md#yesterday-last-week-last-month) · [cumulativeReading](../03.referenz/02.states-und-meldungen.md#meter-readings-cumulative)

## How do I visualize the values in VIS, Flot, HabPanel and the history?

<!-- abschnitt: prio=B; gewicht=8; readme=missing; cluster=outputs-viz-22,periods-24; features=output-statistics-json,current-year-previous,output-tree-layout,rollover-previous-timestamps -->
<!-- muss beantworten: Diagramme, Historie-Anbindung, Tageswerte mit Datum speichern/exportieren. -->

SourceAnalytix delivers states, not charts. For curves, record states with a history adapter and show them in Flot, eCharts, Grafana or a VIS widget. For tables without a database, `statisticsJson` holds all values of the current year.
<!-- quelle: code=main.js; code=lib/statistics-json.js; forum=767608; forum=964967; forum=1359624 -->

<!-- bild: Flot-Diagramm mit Tagesbalken aus 01_previousDay -->

The previous periods are timestamped 23:59:59 on the last day of their period, even if a rollover was caught up later. Yesterday's value therefore lands on yesterday in the history, and you get a list of daily values with dates.
<!-- quelle: code=main.js; code=lib/calculation.js; forum=277925; forum=585336 -->

Bind single values directly, for example `01_currentDay` for "Today". With the "Weekday" option, the days of the current week are under `currentYear.<category>.currentWeek`.
<!-- quelle: code=main.js; code=admin/jsonConfig.json; code=admin/i18n/en.json -->

**See also:** [Is there a JSON with all values?](../03.referenz/02.states-und-meldungen.md#json-values-vis) · [States for weeks, months and weekdays](../03.referenz/02.states-und-meldungen.md#week-month-quarter-states-weekdays)

## How do I read SourceAnalytix values in a script?

<!-- abschnitt: prio=B; gewicht=6; readme=missing; cluster=periods-22,upgrade-migration-other-31; features=year-statistics-archive,current-year-previous,output-statistics-json,source-output-id,output-tree-layout -->
<!-- muss beantworten: State-IDs finden, Vorjahresmonat dynamisch lesen, getUsedOutputIds. -->

With `getState`. Every value is a state under `sourceanalytix.0.<device>`, where `<device>` is the "Technical ID" in the source's detail view (under "For experts"). You read past years by putting the year into the ID.
<!-- quelle: code=src-admin/src/SourceDetail.tsx; code=main.js; code=lib/output-id.js; forum=1206276; forum=1166734 -->

This month and the same month last year:

```javascript
const root = 'sourceanalytix.0.power';
const months = ['01_January', '02_February', '03_March', '04_April', '05_May', '06_June',
    '07_July', '08_August', '09_September', '10_October', '11_November', '12_December'];
const now = new Date();
const month = months[now.getMonth()];

const thisMonth = getState(`${root}.currentYear.consumed.03_currentMonth`).val;
const lastYearId = `${root}.${now.getFullYear() - 1}.consumed.months.${month}`;
const lastYear = existsState(lastYearId) ? getState(lastYearId).val : null;

log(`This month: ${thisMonth}, last year: ${lastYear}`);
```

Last year's folder only exists if "Year statistics" › "Months" was on back then. For last month or last year you don't need a date: `03_previousMonth` and `05_previousYear`.
<!-- quelle: code=io-package.json; code=admin/jsonConfig.json; code=main.js -->

All technical IDs with their source datapoint:

```javascript
sendTo('sourceanalytix.0', 'getUsedOutputIds', {}, result => log(JSON.stringify(result)));
```
<!-- quelle: code=main.js -->

Don't write to SourceAnalytix states; the next value overwrites them. For corrections, use the [source's actions](02.zaehlerstaende-korrigieren.md#correct-wrong-too-high-negative).
<!-- quelle: code=main.js -->
