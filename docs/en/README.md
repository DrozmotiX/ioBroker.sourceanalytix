# SourceAnalytix – Documentation

SourceAnalytix calculates consumption, delivery and costs per day, week, month, quarter and year from meter or power datapoints.

The documentation is organized around the questions users have asked in the forum and in issues. Every heading is one of these questions.

- **[Getting started](01.erste-schritte/README.md):** Install SourceAnalytix and set up your first meter.
- **[Guides](02.anleitungen/README.md):** Task-based guides: set up sources, correct meter readings, enter prices, evaluate values and maintain the adapter.
- **[Reference](03.referenz/README.md):** All settings, generated states, messages and log entries for lookup.
- **[Troubleshooting](04.fehlerbehebung/README.md):** The most common error messages and wrong values, and what helps.
- **[Background](05.hintergrund/README.md):** How the adapter calculates, explained briefly.
